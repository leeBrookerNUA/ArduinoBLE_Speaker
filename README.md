# ArduinoBLE_Speaker
Controlling a DFRobot Speaker via Bluetooth for Year 3 CTR Masterclass number 1

# Requirements
## Hardware
- Arduino Uno R4 Wifi
- DFRobot Speaker V2.0
- Jumper wire
- Breadboard
- An Android/IOS Device

## Software
- Arduino IDE
- The Light Blue App
- [Arduino PlayMelody](https://docs.arduino.cc/built-in-examples/digital/toneMelody/)
- [tone()](https://docs.arduino.cc/language-reference/en/functions/advanced-io/tone/)

# Instructions
- Download the Arduino IDE and clone this GitHub reposetory
- Download Light Blue onto your phone
- Recreate the circuit following the EasyEDA schematic
- Upload the C++ code onto the Arduino
- Use Light Blue to connect to the Arduino, it should be labled "Speaker"
- Input numbers 1-7 to play a different note
